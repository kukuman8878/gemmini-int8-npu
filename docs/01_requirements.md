# 01 需求说明

版本：v0.1（草案） | 日期：2026-10-29 | 状态：随实现迭代更新

## 1. 功能需求

| 编号 | 需求 | 说明 |
|:---|:---|:---|
| F1 | signed INT8×INT8→INT32 乘累加 | A、B 为 signed 8bit；乘积为 signed 16bit；累加为 signed 32bit，无饱和、无量化截断 |
| F2 | 4×4 OS 脉动阵列 | A 左→右、B 上→下传递，PE 保存局部 C[i,j] 累加 |
| F3 | 单 tile 矩阵乘 | 计算 C[i,j]=Σ_{k=0..K-1} A[i,k]·B[k,j]，K ∈ 1…256；A:4×K、B:K×4、C:4×4 |
| F4 | valid/ready 握手 | 输入按拍接受，背压时数据保持稳定 |
| F5 | 任务生命周期 | IDLE→LOAD→COMPUTE→DRAIN→OUTPUT，busy/done 语义明确 |
| F6 | 连续任务与复位 | 任务间无旧状态泄漏；任意状态复位可恢复 |
| F7 | 大矩阵切块 | 首版由主机测试驱动切块（K 分块、零填充），RTL 不做全 GEMM 调度 |

## 2. 非功能需求

| 编号 | 需求 | 说明 |
|:---|:---|:---|
| N1 | 可综合 | 无锁存器意外推断、无组合环、无多驱动（lint 通过） |
| N2 | 单时钟域 | 首版无 CDC |
| N3 | 可验证 | Golden/Scoreboard/回归可复现；随机种子固定 |
| N4 | 可测量 | 面积/时序结论必须来自同一工艺库/约束/工具版本的报告 |

## 3. 明确不做（V1）

- 不做 bias/ReLU/饱和/量化缩放（保持输出为精确整型）。
- 不内置全尺寸 GEMM 调度器（切块在测试端）。
- 不承诺功耗结论（无活动率/功耗库数据）。
- 不把 Gemmini 官方代码当自研成果；官方仅作对照。
